# SQL fundamentals for junior data analysts

SQL is commonly used to retrieve and summarize relational data. Practice SELECT, WHERE, ORDER BY, GROUP BY, HAVING, JOIN, and aggregate functions. Understand primary keys, null values, duplicates, and how joins can change row counts. Build a small project that answers business questions with documented queries and explains the results. Use realistic datasets and check outputs rather than memorizing syntax alone.

---

# Intermediate SQL and validation

After the basics, practice common table expressions, subqueries, CASE expressions, window functions, and date handling. Validate queries by checking row counts, join cardinality, missing values, and aggregate totals. Explain assumptions and edge cases. Query performance and indexing may matter for some roles, but the job description should guide preparation priorities.

---

# Python for practical data analysis

Python can support cleaning, exploration, automation, and visualization. Learn pandas for tables, NumPy for numerical operations, and matplotlib for charts. Practice importing CSV files, inspecting data types, handling missing values, merging datasets, grouping records, and exporting reproducible outputs. Document assumptions and limitations. A notebook or script should answer a clear question, not just demonstrate library commands.

---

# Excel and spreadsheet analysis

Useful Excel skills include formulas, lookup functions such as XLOOKUP, PivotTables, charts, conditional formatting, and Power Query. Practice reconciling totals, detecting duplicate records, validating inputs, and documenting transformations. Show how a spreadsheet analysis supports a business decision. Employers vary in the Excel features they require, so review the actual posting.

---

# Tableau and Power BI dashboard design

Data visualization work includes selecting appropriate charts, defining metrics, applying filters, designing accessible layouts, and explaining findings. Learn the distinction between a measure and a dimension, and validate calculations against source data. Avoid misleading axes, unnecessary decoration, and overcrowded dashboards. Explain the audience, business question, and decisions the dashboard supports. Do not claim that a dashboard improved business results without evidence.

---

# Git, portfolios, and data pipelines

Git tracks changes and supports collaboration. Practice git clone, status, add, commit, pull, and push; understand branches and pull requests. A portfolio repository should include a README, data provenance, setup instructions, and a description of results. Never commit API keys, passwords, or confidential datasets. Understand the basic extract-transform-load workflow, data quality checks, and reproducibility; deeper pipeline tools depend on the role.
